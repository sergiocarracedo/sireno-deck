# Phase 09 Plan 02: weather + emoji-selector + media-player + brightness

## Tasks

### Task 1: Port `weather` addon (Open-Meteo)
- File: `packages/cli/src/builtin-addons/weather/schemas.ts` — `WeatherButtonSchema` with `location: { latitude, longitude, name? }`, `units?: 'metric' | 'imperial'`
- File: `packages/cli/src/builtin-addons/weather/domain/fetch.ts` — `fetchWeather(loc)` hits `https://api.open-meteo.com/v1/forecast?latitude=...&longitude=...&current=temperature_2m,wind_speed_10m,weather_code` with 10s timeout; parses JSON
- File: `packages/cli/src/builtin-addons/weather/domain/codes.ts` — WMO weather code → human description map
- File: `packages/cli/src/builtin-addons/weather/buttons/weather.tsx` — single button; uses `useEffect` + `setInterval(600_000)` (10 min default); renders `<LabelValueList>` with temp + wind + description
- File: `packages/cli/src/builtin-addons/weather/index.ts` — `weatherAddon`
- Tests: schema parsing, WMO code mapping
- Acceptance: 1 button type. If no `location` config, render "Configure weather" placeholder.

### Task 2: Port `emoji-selector` addon (4 buttons + 1 deck)
- File: `packages/cli/src/builtin-addons/emoji-selector/schemas.ts` — `EmojiSelectorDeckSchema` with `favorites: z.array(z.string()).default([])`
- File: `packages/cli/src/builtin-addons/emoji-selector/support.tsx` — `CATEGORY_DEFINITIONS` (8 categories with curated emoji lists); `EMOJI_PAGE_SIZE = 32`; `generatePageLabel(label, pageIdx, totalPages)`
- File: `packages/cli/src/builtin-addons/emoji-selector/buttons/category.tsx` — `core:emoji-category-button` (renders a category tile)
- File: `packages/cli/src/builtin-addons/emoji-selector/buttons/entry.tsx` — `core:emoji-emoji-button` (renders one emoji)
- File: `packages/cli/src/builtin-addons/emoji-selector/buttons/launcher.tsx` — `core:emoji-launcher-button` (opens the emoji deck)
- File: `packages/cli/src/builtin-addons/emoji-selector/buttons/back.tsx` — `core:emoji-back-button`
- File: `packages/cli/src/builtin-addons/emoji-selector/index.ts` — `emojiSelectorAddon` with `decks: [emojiSelectorDeck]` that calls `paginateDecks` from `@/core/pagination` and builds per-page decks with `buildPageNavButton`
- Tests: deck generation logic with mocked `paginateDecks`
- Acceptance: 4 button types + 1 deck type. Favorites category is first when populated.

### Task 3: Port `media-player` addon (3 buttons via Phase 07 provider)
- File: `packages/cli/src/builtin-addons/media-player/schemas.ts` — `MediaPlayerButtonSchema` (mostly empty — uses Phase 07 media provider), `MediaMuteButtonSchema`, `MediaVolumeButtonSchema`
- File: `packages/cli/src/builtin-addons/media-player/domain/controller.ts` — `createMediaController({ platform, executor, env, logger })` builds a controller that wraps `createMediaProvider()` from Phase 07; exposes `play/pause/next/prev/setVolume/getVolume/mute/unmute/toggle`
- File: `packages/cli/src/builtin-addons/media-player/buttons/media-player.tsx` — single `core:media-player` button using `<SplitAction>` from Phase 08; left half = prev/play/pause; right half = next/volume; uses `useEffect` to subscribe to media state
- File: `packages/cli/src/builtin-addons/media-player/buttons/media-mute.tsx` — `core:media-mute`
- File: `packages/cli/src/builtin-addons/media-player/buttons/media-volume.tsx` — `core:media-volume`
- File: `packages/cli/src/builtin-addons/media-player/index.ts` — `mediaPlayerAddon`
- Tests: controller shape
- Acceptance: 3 button types. Media actions work on platforms where Phase 07 media provider is implemented (all 3 OSes).

### Task 4: Port `brightness` addon (macOS only)
- File: `packages/cli/src/builtin-addons/brightness/schemas.ts` — `BrightnessButtonSchema` with `action: 'up' | 'down' | 'set'`, `value?: number` (0-100)
- File: `packages/cli/src/builtin-addons/brightness/domain/macos.ts` — `setBrightnessUp() / setBrightnessDown() / setBrightness(value)` shell out to `osascript -e 'tell application "System Events" to key code 144/145'` for up/down; `'set'` uses AppleScript brightness control
- File: `packages/cli/src/builtin-addons/brightness/buttons/brightness.tsx` — single button; macOS branches dispatch to `osascript`; non-macOS renders "Not supported on this platform"
- File: `packages/cli/src/builtin-addons/brightness/index.ts` — `brightnessAddon`
- Tests: macOS mock with `vi.mock('node:child_process', ...)`; non-macOS renders placeholder
- Acceptance: 1 button type. macOS path: actually changes brightness. Other OSes: no-op surface.
