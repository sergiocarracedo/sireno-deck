# Phase 06 Plan 03 — Real-mode CLI Integration

## Context

Plans 06-01 and 06-02 give us the device layer and the renderer. Now we wire them into the CLI commands so that `sireno run` (foreground) and `sireno start` (daemon) actually drive real hardware.

The CLI command surface is in `packages/cli/src/cli/commands/run.ts` and `start.ts`. Both are currently Phase 0 placeholders. We replace them with a real implementation that:
1. Loads config + bootstraps addon registry
2. Discovers devices → if multiple, prompts (or reads device.json)
3. Connects to the selected device
4. Starts the renderer (Playwright + sharp pipeline)
5. Traps SIGINT/SIGTERM, calls renderer.stop() + device.close()
6. Cleans up PID file (for `start`)

A new module `real-mode.ts` extracts the orchestration logic so it can be tested without spawning child processes.
