# Plan 15-02: Base Surfaces + Theme Integration

<objective>
Port the 4 base surfaces (Bars, IconLabel, LabelValueList, SplitAction) from legacy sireno-deck into `src/ui/surfaces/`. Then update both default and light themes to import all components/surfaces from `@/ui/` instead of owning their own implementations. Delete the old `components/` and `surfaces/` subdirectories in both themes. After this plan, themes are thin layers that only ship `ButtonFrame.tsx`, `theme.css`, and an `index.tsx` that re-exports from the base.
</objective>
