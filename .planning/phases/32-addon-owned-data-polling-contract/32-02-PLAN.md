# Plan 32-02: Migrate System-Status To Addon-Owned Polling And Domain Modules

<objective>
Deliver one complete tracer bullet for system-status under the new Phase 32 contract: the addon owns metric polling callbacks, payload typing, and schema-owned cadence defaults while core only schedules and forwards payload data. This plan also moves system-status domain logic from core `/system/*` seams into addon-local modules so ownership aligns with the chosen architecture boundary.
</objective>
