# Plan 23-02: Hardware Startup Placeholder

<objective>
Add a hardware-only boot-state visual that is clearly temporary and clearly Sireno-branded. This slice must stay outside the steady-state runtime deck contract: `start.ts` writes the placeholder while browser startup is genuinely pending, then the first successful captured deck replaces it, and any startup failure still surfaces honestly.
</objective>
