# Plan 03-01: Theme loading and config-driven display buttons

<objective>
Lay the real foundation for Phase 3. Replace the Phase 2 proof-of-life render with the first config-driven deck surface, teach the CLI how to load built-in and custom theme YAML files, and get display-only buttons rendering from the configured main deck. This is the step that turns the project from a rendering demo into an actual deck runtime.
</objective>

- themes/light.yml
- packages/cli/src/config/theme.ts
- packages/cli/src/config/theme.test.ts

<action>
Create the missing repo-level built-in theme assets in `themes/dark.yml` and `themes/light.yml`, plus a representative `config.yml` that exercises the new Phase 3 deck structure.
