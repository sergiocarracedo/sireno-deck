# Plan 02-02: First React-to-device render

<objective>
Implement the first visible rendering tracer bullet for Phase 2. After the device lifecycle is working, this plan proves the actual React-to-image-to-hardware path by rendering a simple text component to key `0`, blanking the rest of the deck, and deduping identical writes so the device is not hammered unnecessarily.
</objective>

Add tests that verify the reconciler produces a renderable description for key `0` and no accidental writes for untouched keys.
</action>
