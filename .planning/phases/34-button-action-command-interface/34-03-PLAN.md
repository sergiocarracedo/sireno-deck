# Plan 34-03: Roll The Shared Command Contract Across Regular Date-Time Buttons

<objective>
Deliver the widened Phase 34 rollout on the bundled date-time addon: every regular date/time button can optionally run nested command gestures through the shared helper, but the locked fallback tiles remain untouched. This slice proves the contract works on non-command-first buttons that previously had no action behavior at all.
</objective>
