# Installation

Get Sireno Deck running on your computer in minutes.

## Prerequisites

- **Node.js** 20 or later
- **pnpm** 8 or later (or npm/yarn)
- A Stream Deck device (optional — emulator available for testing)

## Quick Install

```bash
# Install the CLI globally
pnpm install -g @sireno-deck/cli

# Or use npx
npx @sireno-deck/cli --help
```

## From Source

```bash
# Clone the repository
git clone https://github.com/anomalyco/sireno-deck.git
cd sireno-deck

# Install dependencies
pnpm install

# Build the CLI
pnpm build

# Run directly
pnpm sireno --help
```

## Verify Installation

```bash
sireno --version
```

You should see output like:

```
sireno-deck v0.1.0
```
