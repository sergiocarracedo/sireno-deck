# Plan 17-02: Extract The Core Base Shape And Migrate The First Helper Consumers

<objective>
Deliver the second Phase 17 tracer bullet as one demoable user-facing behavior: the default shared/default button card is now a real core-owned base shape with explicit content helpers, and bundled low-risk buttons consume that API directly instead of depending on hidden renderer conventions.
</objective>

## Tasks

<task id="17-02-01">
<title>Extract the shared/default card into an explicit base-shape renderer</title>
<files>
- packages/cli/src/render/text-image.ts
- packages/cli/src/render/text-image.test.ts
</files>
<action>
Refactor the current shared/default branch in `packages/cli/src/render/text-image.ts` into an explicit base-shape implementation while preserving the already-shipped visuals and explicit prop precedence such as `background`, `fit`, and `accent`. Treat the base shape as the owner of the narrow interaction chrome the current renderer can honestly express; if pressed/held states are not yet surfaced on this path, pin that limitation explicitly in `.planning/phases/17-custom-wrapper-primitives-with-addon/17-UAT.md` instead of implying richer behavior than the code supports. Keep the first rollout narrow: the extracted base shape should serve the text-oriented shared/default path only, and bespoke variants should keep their current bespoke branches untouched.
</action>
<verify>
Run `pnpm --filter sireno-deck-cli exec vitest run src/render/text-image.test.ts` and confirm `17-UAT.md` documents any first-rollout interaction-state limitation if tap/hold visuals are not yet observable on the real path.
</verify>
<done>
The base shape is now an explicit renderer seam instead of a hidden shared-wrapper special case.
</done>
</task>

<task id="17-02-02">

<done>

</done>
</task>
