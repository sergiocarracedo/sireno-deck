# Phase 04 Plan 01 — Public API + WS Protocol + Bridge + Vite Spawn

## Context

Phase 04 wires the React frontend to the CLI. Before any UI exists, we need the data plane: shared types (public API), the wire protocol (zod-validated), the WS server (with token handshake), and the vite child-process manager.

These four modules are pure infrastructure — they don't render anything, but everything downstream depends on them. Plan 02 builds the vite plugin + frontend React app on top. Plan 03 wires the frontend to the bridge via WS client + React hooks.

Locked decisions from CONTEXT.md (do not re-litigate):
- **Addon frontend module loading**: build-time static import (vite plugin imports each addon's `frontend.main` into the bundle).
- **State sync model**: per-channel pub-sub with debounced `state` message.
- **Reconnect strategy**: auto-reconnect with exponential backoff (1s → 30s cap) — handled in the frontend (Plan 03), not the bridge.
