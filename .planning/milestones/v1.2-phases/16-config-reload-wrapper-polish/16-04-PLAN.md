# Plan 16-04: Remove The Shared Footer And Add Narrow Per-Button Accent Overrides

<objective>
Finish the visual polish slice for Phase 16. A completed plan should leave shared-wrapper buttons cleaner by removing the theme-name footer and let authors tune one button's accent treatment with an explicit narrow override, without turning wrapper/style config into a general-purpose style language.
</objective>

## Tasks

<task id="16-04-01">
<title>Add one explicit button-level accent override to the config and render contracts</title>
<files>
- packages/cli/src/core/schemas.ts
- packages/cli/src/config/loader.test.ts
- packages/cli/src/render/types.ts
- packages/cli/src/render/reconciler.ts
</files>
<action>
Introduce one narrow per-button config field for shared-wrapper accent overrides. Validate it deterministically in the existing config schema, allow either theme-token values or raw color values, and carry it through the public render/reconciler contract without replacing the current explicit wrapper/style ids or broadening config into a nested styling object.
</action>
<verify>
Run `grep -n "accent" packages/cli/src/core/schemas.ts packages/cli/src/render/types.ts packages/cli/src/render/reconciler.ts`.
</verify>
<done>
The config/render contract can express one explicit shared-wrapper accent override per button while staying narrow.
</done>
</task>

<task id="16-04-02">
<title>Remove the shared footer and render accent overrides observably on the shared/default path</title>
<files>
- packages/cli/src/render/text-image.ts
- packages/cli/src/render/text-image.test.ts
- packages/cli/src/cli/commands/start.ts
</files>
<action>
Update the shared/default SVG branch so it no longer renders the current theme-name footer at all. Then apply the new explicit accent override when the shared wrapper path is used, resolving theme tokens against the active theme and raw colors directly, while leaving existing explicit props and wrapper/style behavior authoritative. Add focused render tests that make both changes observable: footer removal changes the shared card output, and token/raw accent overrides both produce distinct expected output on the shared path.
</action>
<verify>
Run `pnpm --filter sireno-deck-cli test -- src/render/text-image.test.ts src/config/loader.test.ts`.
</verify>
<done>
Shared-wrapper visuals are cleaner, and per-button accent customization works without widening the renderer into a styling engine.
</done>
</task>

<must_haves>
- Footer removal is complete, not merely hidden by default.
- Accent customization remains one explicit button-level knob rather than a general-purpose style language.
- Token and raw-color inputs are both supported and visibly affect the shared-wrapper output.
</must_haves>
