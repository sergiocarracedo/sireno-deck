# Plan 03-03: Change-deck navigation and automatic back button

<objective>
Finish Phase 3 by adding real deck navigation. After the runtime can already render themed buttons and execute commands, this plan introduces multiple deck definitions, change-deck buttons, and the auto-generated back behavior needed for sub-decks. This is the point where Sireno Deck stops being a flat board of buttons and becomes a navigable deck system.
</objective>
