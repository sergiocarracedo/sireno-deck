# Plan 29-01: Remove The Legacy Button Contract End To End

<objective>
Land the hard-cut slice Phase 29 explicitly asked for: the product boots and renders through the mounted `render(props)` definition contract directly, not through a hidden instance-era adapter. This slice has to come first because every later built-in cleanup is fake if runtime and tests still preserve `createInstance(...)` as the real seam.
</objective>

## Tasks

<task id="29-01-01">
<title>Delete the legacy public button-definition seam and keep `ButtonSurface` as an honest metadata boundary</title>
<files>
- packages/cli/src/addon/api.ts
- packages/cli/src/index.ts
</files>
<action>
Refactor `packages/cli/src/addon/api.ts` so `AddonButtonDefinition` describes the mounted `render(props)` contract directly, remove the legacy instance-era public types (`LegacyAddonButtonDefinition`, `AddonButtonInstance`, and the `CreateAddonButtonInstanceOptions` surface), and stop implementing `defineMountedButton(...)` as an adapter back into `createInstance(...)`. Keep the metadata story explicit while doing this: `ButtonSurface` may stay as the wrapper that carries `data-sireno-full-surface` and `data-sireno-sample-interval-ms`, but it should be authored truthfully in TSX/class-based form rather than treated as leftover legacy presentation scaffolding. Update `packages/cli/src/index.ts` so the public root export matches the new contract names exactly and does not preserve a dead alias.
</action>
<verify>
Run `grep -n "LegacyAddonButtonDefinition\|AddonButtonInstance\|createInstance\|ButtonSurface" packages/cli/src/addon/api.ts packages/cli/src/index.ts` and confirm the legacy type names are gone while `ButtonSurface` remains the explicit metadata surface.
</verify>
<done>
The public addon/built-in authoring contract tells the truth: mounted `render(props)` is the button seam, and the metadata wrapper is explicit instead of being entangled with a hidden adapter.
</done>
</task>

<must_haves>
- Do not replace the deleted bridge with another hidden compatibility union or heuristic runtime branch; the user explicitly chose a hard cut.
- Do not silently drop `ButtonSurface` metadata semantics while removing `createElement(...)`; `full_surface` and `sample_interval_ms` still matter to runtime.
- Keep the contract change reviewable in the type surface and root export rather than hiding it inside runtime only.
</must_haves>
