# Plan 33-01: Land The Real Tailwind Build And Browser Delivery Seam

<objective>
Establish the honest runtime contract Phase 33 depends on before migrating authoring surfaces. This slice delivers one end-to-end behavior: the browser-rendered deck loads a real prebuilt Tailwind stylesheet asset as its utility source, while Sireno still owns resolved `--sireno-*` theme variables and product-only runtime glue. The same contract must hold through the shipped browser document and the emulator DOM patch path.
</objective>
