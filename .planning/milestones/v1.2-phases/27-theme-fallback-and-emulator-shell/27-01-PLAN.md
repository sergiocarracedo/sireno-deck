# Plan 27-01: Collapse Theme Fallback Onto The Built-In Default Theme

<objective>
Delete the last lying theme seam end to end: local YAML themes stop resolving at all, and every default-frame fallback comes from the manifest-backed built-in default theme package that already ships `index.ts` plus `ButtonFrame.tsx`. This keeps one truthful theme model and makes `ButtonFrame.tsx` edits participate in the same watched runtime graph the CLI already reloads.
</objective>
