# 58-01 — Profile browser capture loop

> Phase 57 proved the runtime hop chain is fast (avg=0.37ms). The remaining ~1s lives in the browser capture loop (`runCaptureLoop`) and the hardware USB write. Phase 58-01 instruments the capture loop so Phase 58-02 can ship a targeted fix.

## Context

Phase 57 findings (in-process): runtime hop chain avg=0.37ms, p95=0.79ms. The perceived 1s delay is NOT in runtime JS. It must be in: (a) Playwright Chromium screenshot wait, (b) sharp crop, (c) hardware USB write, (d) 250ms steady-state capture cadence (Phase 35 territory).

Phase 58 decisions (CONTEXT.md):
- Extend `browser-renderer.ts` with `SIRENO_PROFILE=1` env-var-gated `markHop()` calls
- Do NOT change any function signatures (Phase 57 lesson learned)
- Profile back-button AND weather page scenarios; let measurement decide if they share root cause

## Tasks

### Task 1: Add SIRENO_PROFILE instrumentation at capture loop hop boundaries

**File:** `packages/cli/src/render/browser-renderer.ts`

Add a `SIRENO_PROFILE=1` env-var-gated `markHop(name)` helper at the top of the file. Place `markHop()` calls at the following 7 hop boundaries (use a `// INSTRUMENT: ...` comment at each call site for easy audit/revert):

1. `updateDeck` body entry (line ~392) — `markHop('updateDeck.entry')`
2. `runCaptureLoop` per-tick start (line ~299) — `markHop('runCaptureLoop.tick')`
3. `waitForNextCaptureWindow` start (line ~270) — `markHop('waitForNextCaptureWindow')`
4. `ensurePage` resolution in capture loop (line ~342) — `markHop('ensurePage')`
5. `activePage.screenshot` call (line ~346) — `markHop('screenshot.before')` and `markHop('screenshot.after')`
6. `cropDeckCaptureToKeyBuffers` (line ~352) — `markHop('crop.before')` and `markHop('crop.after')`
7. `frameHandler?.(...)` call (line ~356) — `markHop('frameHandler.before')` and `markHop('frameHandler.after')`

**Implementation:**
- Module-level: `const SIRENO_PROFILE = process.env.SIRENO_PROFILE === '1'`
- `markHop(name)` — when env var unset, returns immediately (zero overhead); when set, reads `process.hrtime.bigint()`, computes delta from last timestamp for that hop, calls `console.log(JSON.stringify({ hop: name, ms: Number(delta) / 1_000_000 }))` or uses the runtimeLogger if available.
- Capture delta = `now - prevTimestamps.get(name) || 0`. Set `prevTimestamps.set(name, now)`.
- Do NOT mutate any runtime state — only read hrtime and log.

**Verify:** `pnpm --filter sireno-deck-cli build && SIRENO_PROFILE=1 pnpm cli:dev emulate` — JSON log lines appear on stdout. Run the test suite and confirm no new failures.
**Done:** Instrumentation committed; logs visible when env var set; no test regressions.
