# Plan 01-02: Sweep Raw Typography Callers Onto The Honest Contract

<objective>
Complete the Phase 1 contract cut on real shipped surfaces: raw typography classes stop acting as the implicit sizing path, built-ins use `Text` where they are actually rendering text, and the remaining tightly owned seams are updated explicitly instead of being left as accidental backdoors. This slice matters because the phase decision was a real sweep, not a partial cleanup hidden behind one improved component.
</objective>

## Tasks

<task id="01-02-01">
<title>Migrate built-in text-node callers from raw typography wrappers to explicit `Text` semantics</title>
<files>
- packages/cli/src/builtin-addons/date-time/buttons/date-time.tsx
- packages/cli/src/builtin-addons/date-time/buttons/analog-clock.tsx
- packages/cli/src/builtin-addons/date-time/buttons/calendar-sheet.tsx
- packages/cli/src/builtin-addons/date-time/buttons/locked-time-tile.tsx
- packages/cli/src/builtin-addons/core-buttons/buttons/action.tsx
- packages/cli/src/builtin-addons/emoji-selector/support.tsx
</files>
<action>
Sweep the known built-in and support-layer text-node callers that still wrap text in `font-main`, `font-aux`, or `font-mono` spans. Wherever the caller is rendering real text content, move typography, tone, and any explicit size intent onto `Text` itself and remove the outer raw typography wrapper so the final sizing path is unambiguous. Keep the visual intent of each surface intact, but do not preserve implicit compatibility shims; the point of this slice is to make the contract cut visible in shipped code paths.
</action>
<verify>
Run `pnpm --filter sireno-deck-cli exec vitest run src/builtin-addons/date-time/index.test.ts src/builtin-addons/core-buttons/index.test.ts src/builtin-addons/emoji-selector/index.test.ts`.
</verify>
<done>
Built-in text surfaces now express text semantics through `Text` directly instead of depending on raw role classes to supply the final size implicitly.
</done>
</task>

<task id="01-02-02">
<title>Close remaining tightly owned raw typography seams and rewrite regression expectations to the new contract</title>
<files>

- packages/cli/src/render/dom-host-deck-document.tsx
- packages/cli/src/render/dom-host.test.tsx

- packages/cli/src/builtin-addons/core-buttons/index.test.ts

<action>
Update the remaining tightly owned non-`Text` seams discovered during research so they no longer depend on raw role classes for implicit final sizing. `packages/cli/src/ui/Chip.tsx` should keep its presentational role but must stop relying on raw typography sizing as a hidden contract, and `packages/cli/src/render/dom-host-deck-document.tsx` should stop putting `font-main` on the document body as the browser-wide sizing default. Then rewrite the affected tests so they no longer assert the old raw class strings as the supported outcome; instead, prove the new explicit contract through the rendered metadata, utility stylesheet, and per-surface behavior that should remain stable after the sweep.
</action>
<verify>

</verify>
<done>
The old implicit role-class sizing seam is closed across the remaining owned surfaces, and regression tests now guard the explicit Phase 1 contract instead of the superseded raw-class output.
</done>
</task>
