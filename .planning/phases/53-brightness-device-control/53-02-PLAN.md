# Plan 53-02: Brightness button built-in addon

<objective>
A new built-in `brightness` addon provides a `brightness` button type that exercises the device layer in production. Tapping the button cycles the brightness through 0/25/50/75/100 percent and calls `setBrightnessAll(percentage)`. The button is the first real consumer of the phase 53-01 registry, ahead of the larger phase 54 settings deck. It ships with the CLI as a first-party addon so users can add a brightness control to their deck without writing any code.
</objective>
