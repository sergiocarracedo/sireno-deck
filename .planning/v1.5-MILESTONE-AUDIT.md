### E2E Flows

- **Weather lifecycle:** Configure city name → geocoder query → cache store → fetch forecast with timezone → render multi-page cycle (main → data → hourly → daily). ✓
- **Brightness cycle:** Configure brightness button → tap cycles 0→25→50→75→100→0 → `setBrightnessAll()` applies to all open devices → device handle persists last brightness across reconnect. ✓
- **Settings navigation:** Tap main-deck settings entry → navigate to settings deck → brightness up/down tap → `setBrightnessAll()` → back button to previous deck. ✓
- **Lock deck:** Navigate to lock deck while unlocked → system back present → session locks → return to lock deck → no system back button. ✓
- **Active-app overlay:** Configure addon deck with `process_names` → launch matching app → overlay deck replaces view → toggle button dismisses overlay → app closes → overlay auto-clears. ✓
