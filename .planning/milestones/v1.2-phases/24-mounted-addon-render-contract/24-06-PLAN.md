# Plan 24-06: Reduce Emulator Deck-Mount Churn On Polled Updates

<objective>
Close the UAT-reported `#deck-mount` churn without lying about where the 1-second clock cadence comes from. The date-time button should keep driving updates through its button-level polling contract, but the emulator should stop republishing those updates as full deck-mount subtree replacement when a narrower mounted update path is available.
</objective>
