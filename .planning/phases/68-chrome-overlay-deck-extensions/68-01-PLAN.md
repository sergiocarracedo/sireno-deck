# Plan 68-01: Chrome overlay deck extensions (CHROME-01)

## Context

CHROME-01 (REQUIREMENTS.md): "The config chrome overlay deck includes additional keystroke-action buttons: unclose tab (Ctrl+Shift+T), incognito (Ctrl+Shift+N), and other common Chrome keyboard shortcuts".

The current chrome deck in `config.yml` (lines 79-87) has a single button at position 0: `label: 'New tab'` with icon, but **no `key_macro` and no `commands`** — the button is a dead placeholder (the `action` button's `onTap` is a no-op when neither is set, per `packages/cli/src/builtin-addons/core-buttons/buttons/action.tsx:30-39`). CHROME-01's "additional keystroke-action buttons" intent is violated by the placeholder.

This plan delivers 7 keystroke-action buttons (1 replacement + 6 new) in the chrome deck, all using the existing `action` + `key_macro: "string"` primitive. No new code, no new schema, no new API. A fixture + loader test provide regression coverage for the config-only change.

## Notes

- **No new code, no new schema, no new API.** This plan is config + fixture + test only. The vertical slice is: chrome deck shows 7 keystroke buttons → fixture proves the shape → test asserts it. Each task is mechanical.
- **System back button is runtime-injected at n-1** by Phase 66's `SPLIT_ACTION_TYPE` wiring. With 7 buttons at positions 0-6, n-1 = 14 on a 15-key deck is free — no collision. If the chrome deck ever expands past position n-2, it will collide and the runtime will (per Phase 66 semantics) suppress one of the buttons. The test's assertion that no button is at position 7+ is a guardrail, not a runtime check.
- **Icon names are Lucide identifiers** — `square-plus`, `x`, `rotate-ccw`, `eye-off`, `rotate-cw`, `refresh-cw`, `terminal`. If any of these names is missing from the Lucide bundle, the runtime will show a missing-icon placeholder (the bundled `Icon` component falls back to a "?" glyph). UAT will catch this; the unit test does not need to validate icon glyphs.
- **The fixture uses `theme: dark` and a minimal main deck** so it can be loaded standalone. The main deck has a single action button (no real-world purpose — it's a placeholder to satisfy the schema's `main_deck` requirement). Real users will not run with this fixture as their actual config; it's only for tests.
