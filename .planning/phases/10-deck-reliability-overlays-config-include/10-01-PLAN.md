<action>
Create `packages/cli/src/render/push-raw-image.ts` exporting:

```ts
export interface PushRawImageOptions {
  imagePath: string          // absolute path to source image
  device: { getKeyCount(): number; fillKeyBuffer(i: number, buf: Buffer): Promise<void> }
  logger: pino.Logger
  background?: string        // CSS color; default "#000000"
}

export async function pushRawImage(opts: PushRawImageOptions): Promise<void>
```

Pipeline (mirror `browser-renderer.ts:160-172`):
1. Load the image at `opts.imagePath` with `sharp(...)`. If the load throws, log a warning with the file path and return without throwing.
2. Get `keyCount = device.getKeyCount()`. Compute `grid = gridForKeyCount(keyCount)` (import from `@/device/models`).
3. Resize/composite: build a black canvas of `grid.columns * 72 × grid.rows * 72` with sharp, composite the loaded image centered (use `fit: 'contain'`). Remove alpha → raw RGB → one big buffer.
4. For each key index 0..keyCount-1: extract the 72×72 cell with sharp's `.extract({ left, top, width: 72, height: 72 })` → `.removeAlpha()` → `.raw()` → `Buffer`. Call `await device.fillKeyBuffer(keyIndex, buffer)`. Push promises in parallel with `Promise.all` so all keys receive the splash in one shot.
5. Log info `pushed raw image: ${imagePath}, ${keyCount} keys`.
6. On any thrown error during sharp operations, log warn with the error and return — never throw.

Test (`push-raw-image.test.ts`):
- Mock a fake device with `getKeyCount() → 15` and a `fillKeyBuffer` vi.fn.
- Call `pushRawImage` with a 200×200 PNG fixture (write a tiny PNG inline as `Buffer.from(...)`).
- Assert `fillKeyBuffer` was called 15 times, each call received a 72×72×3 = 15,552-byte buffer, and the first byte is 0 (black background present at edges).
- Test failure mode: missing imagePath → no calls, no throw.
</action>
<verify>
`pnpm --filter @sireno-deck/cli test push-raw-image` passes.
</verify>
<done>
`pushRawImage` produces 72×72 raw RGB buffers per key and handles missing-file gracefully.
