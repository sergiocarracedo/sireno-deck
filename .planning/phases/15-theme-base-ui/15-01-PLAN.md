# Plan 15-01: Base Primitives + Context

<objective>
Port the 5 base primitive components (Text, Icon, Label, Chip, TapIndicator) and the theme override context system from legacy sireno-deck into a new `src/ui/` directory. Add a minimal `cn` utility for conditional class names and a `negative-color` utility for BarsSurface contrast. After this plan, an addon frontend can `import { Text } from "@/ui/"` and render rich markup with full legacy behavior.
</objective>
