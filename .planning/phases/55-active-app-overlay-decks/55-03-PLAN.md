# 55-03 — Gap closure: locked-deck button count + settings logo-version

> Closes 2 pre-existing issues discovered while running UAT for phase 55.
> Neither issue is introduced by phase 55 work — they are stale test/
> rendering seams from quick tasks 037/038 and Phase 3 gap-closure.
> They block full greenness of the test suite.

## Context

UAT for phase 55 (verify-work) ran 14 tests, 10 passed, 2 issues:

- **6a**: `internal-decks.test.ts:100` expects 5 buttons on the internal
  locked deck, but `runtime.ts:244-258` `createInternalLockedDeck`
  produces 3 buttons (hour, separator, minute). The 5-button assumption
  is from the pre-Phase-3-closure centered HH:MM layout; Phase 3
  gap-closure ("honest larger-time-line fix") changed it to 3.
- **6b**: `runtime.ts:274` declares
  `{ id: 'logo-version', position: 3 }` in `INTERNAL_SETTINGS_DECK`, but
  `renderSettingsButton` in `settings-deck.tsx` only handles
  `brightness-up` / `brightness-down` / `current-brightness` and falls
  through to the `empty` placeholder for `logo-version`. Quick 037
  ("Replace main deck home button with logo + cli version") moved the
  logo+version display to the settings deck but did not wire the
  rendering seam.
