# brightness

Single button that adjusts screen brightness. Tap = action (up/down/set). The button shows the current brightness as a bar.

Uses the OS provider from `os-providers/`:

- Linux: `xrandr` / `brightnessctl` (whichever is available)
- macOS: `osascript`
- Windows: PowerShell + WMI

## Buttons

| Type              | Description                                      |
| ----------------- | ------------------------------------------------ |
| `core:brightness` | Single button: shows + adjusts screen brightness |

## Config

```yaml
- position: 5
  type: core:brightness
  config:
    action: up # "up" (default), "down", or "set"
    value: 75 # required for "set" (0-100); ignored for up/down
```

### Gesture semantics

- **Tap** on a `core:brightness` button → executes the configured `action`.
- **Hold** on a `core:brightness` button → toggles between `up` and `down` for fine-grained adjustment.

## Example

In your `settings` deck (auto-generated by `internal-settings`):

```yaml
decks:
  settings:
    name: Settings
    buttons:
      - position: 0
        type: core:brightness
        config: { action: up }
```

Run `xrandr --output eDP-1 --brightness 0.75` (Linux) to verify the action works on your system.
