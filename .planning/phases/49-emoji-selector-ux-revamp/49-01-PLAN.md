## Context

CONTEXT.md locked the catalog source as a hand-curated JSON file modeled on the piliapp.com group structure, with composite groups pre-split (e.g. `Smileys and People` → `Smileys` + `People`). The HID output is a per-OS shim: Linux=xdotool, macOS=pbcopy+osascript, Windows=Set-Clipboard+SendKeys. The current `CATEGORY_DEFINITIONS` is a hand-rolled 6-category list; the current `EmojiEntryButtonSchema` has only `select_command`. This plan ships the data file, the shim module, and the schema extension.

The hand-curated catalog is shipped as a JSON file in the addon. The data is curated from the piliapp.com reference (https://es.piliapp.com/emoji/list/) — piliapp is a reference for the group structure, our data is the curated subset. piliapp's composite groups (e.g. "Smileys and People") are pre-split into separate entries. Each entry has the unicode character and the conventional `:shortcode:` form.

### 49-01-03: Add the per-OS shim module

- **file**: `packages/cli/src/builtin-addons/emoji-selector/os-shims.ts`
- **action**: Create a module that resolves the per-OS HID command for a given payload (the emoji character or shortcode string). Export `resolveTypeCommand(payload, osType)` and `resolveShortcodeCommand(payload, osType)`. The resolution is:
  - `linux`: `xdotool type --clearmodifiers <quoted-payload>` with the payload single-quoted for shell safety.
  - `darwin` (macOS): `pbcopy <<< <payload> && osascript -e 'tell application "System Events" to keystroke "v" using {command down}'` (Cmd+V after clipboard set, since AppleScript keystroke can't send unicode).
  - `win32` (Windows): PowerShell snippet: `Add-Type -AssemblyName System.Windows.Forms; [System.Windows.Forms.Clipboard]::SetText('<payload>'); [System.Windows.Forms.SendKeys]::SendWait('^v')`.
  - For any other `osType`: return a `{ unsupported: true, osType }` marker.
  - Also export `getShimUnsupportedReason(osType)` returning a short human-readable reason (e.g. `HID shim not available for OS 'freebsd'`) for the render path to show.
- **verify**: `cd packages/cli && npx tsc --noEmit -p . 2>&1 | head -10`.
- **done**: `os-shims.ts` exports both resolver functions; covers linux/darwin/win32/other.
