# Plan 03-02: Action buttons and periodic command displays

<objective>
Add the first real interaction path to the deck runtime. After display-only buttons are working, Phase 3 needs command execution on tap and periodically refreshed command-backed labels. This plan should prove the input loop, the action side effect boundary, and the narrower per-button polling path that later live-data buttons will reuse.
</objective>

<action>
Update `packages/cli/package.json` with the command execution dependency chosen in research.
