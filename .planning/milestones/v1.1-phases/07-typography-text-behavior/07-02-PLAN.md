# Plan 07-02: Optional Shared Wrapper Contract

<objective>
Expose the smallest render-contract expansion that lets buttons intentionally use the shared wrapper/text behavior from Plan 07-01 while preserving the escape hatch for bespoke visuals. This keeps Phase 7 aligned with the addon-first renderer model instead of hiding the contract inside internal helpers.
</objective>

## Tasks

<task id="07-02-01">
<title>Expand render prop types with minimal shared wrapper and clip fields</title>
<files>
- packages/cli/src/render/types.ts
- packages/cli/src/render/reconciler.ts
- packages/cli/src/render/jsx.d.ts
</files>
<action>
Update `packages/cli/src/render/types.ts` with the smallest additional prop surface needed to express the optional shared wrapper/text contract established in Phase 7. Keep the contract narrow and custom: add only the minimal fields required for shared wrapper text slots and explicit clip behavior, and preserve backward compatibility for existing `deck-button`, `deck-text`, and `deck-surface` usage. Then thread those props through `packages/cli/src/render/reconciler.ts` and `packages/cli/src/render/jsx.d.ts` so helper-based and explicit JSX authoring share the same Phase 7 contract.
</action>
<verify>
Run `pnpm --filter sireno-deck-cli exec vitest run src/render/reconciler.test.tsx`.
</verify>
<done>
The render type surface expresses the optional shared wrapper/text contract without introducing DOM-like props or forcing all buttons through one shell.
</done>
</task>

<task id="07-02-02">
<title>Carry the new shared wrapper fields through runtime rendering</title>
<files>
- packages/cli/src/render/reconciler.ts
- packages/cli/src/cli/commands/start.ts
</files>
<action>
Extend `RenderDescription` collection and the runtime render path in `packages/cli/src/cli/commands/start.ts` so any new Phase 7 wrapper/text fields make it from addon render output to `renderTextImage()`. Keep existing fields such as `label`, `subtitle`, `displayValue`, `detailLines`, and `variant` intact, and do not widen the runtime to interpret marquee or ellipsis. This task is complete only when the new data can flow end-to-end for buttons that opt into the shared wrapper while bespoke visuals remain free to avoid those props entirely.
</action>
<verify>
Run `pnpm --filter sireno-deck-cli exec vitest run src/render/reconciler.test.tsx src/render/text-image.test.ts`.
</verify>
<done>
Runtime rendering accepts the new optional wrapper/text fields end-to-end, and existing button variants still render through the same start command path.
</done>
</task>
