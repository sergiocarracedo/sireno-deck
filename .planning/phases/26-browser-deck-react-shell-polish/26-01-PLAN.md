# Plan 26-01: Shared React Deck Document And Shell

<objective>
Turn the browser deck page into one honest React composition surface instead of a string-assembled shell, while keeping the final output contract the same: `renderDomDeck(...)` still returns HTML text for the browser renderer and emulator, but the document/head/body/deck shell now come from a shared React tree with explicit empty slots and moderate Stream Deck-style chrome.
</objective>
