# Plan 66-01: SplitActionSurface Component

<objective>
Create the SplitActionSurface component in src/ui/surfaces/. It accepts primary and optional secondary ReactElement props and renders in two modes: single full-surface (mode 1) or /-style diagonal split (mode 2). The diagonal split uses clip-path: polygon() for the triangular regions and CSS transform: scale() for fitting. Supports theme overrides. Export from ui/index.ts. Add focused unit tests.
</objective>

The component:

3. **Mode 2** (both provided): renders both sub-surfaces in absolutely-positioned containers with:

   - Each container wraps children in a div with `transform: scale(0.7)` (approximate — adjust based on visual testing)
   - The outer wrapper is `position: relative;` to establish a containing block for the absolute children
   - Render primary first in DOM order, secondary second (so secondary overlaps on the diagonal line per stacking context rules)
