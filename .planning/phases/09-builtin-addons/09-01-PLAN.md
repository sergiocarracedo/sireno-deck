# Phase 09 Plan 01: date-time + value-display + system-status

## Tasks

### Task 1: Port `date-time` addon (6 buttons)
- File: `packages/cli/src/builtin-addons/date-time/schemas.ts` — zod configs for the 6 buttons (BuiltinDateTimeButtonSchema, BuiltinTimePresetButtonSchema, BuiltinAnalogClockButtonSchema, BuiltinDateButtonSchema, BuiltinClockButtonSchema, LockedTimeTileButtonSchema)
- File: `packages/cli/src/builtin-addons/date-time/format.ts` — port `formatDigitalDateTimeLabel` using `Intl.DateTimeFormat` (no dayjs dep). Default format `'DD/MM/YYYY HH:mm:ss'`; `<markup>` tags preserved literally.
- File: `packages/cli/src/builtin-addons/date-time/buttons/date-time.tsx` — `core:date-time` button (full format)
- File: `packages/cli/src/builtin-addons/date-time/buttons/time.tsx` — `core:time` button (variant `'default' | 'big'`)
- File: `packages/cli/src/builtin-addons/date-time/buttons/date.tsx` — `core:date` button (locale + time_zone)
- File: `packages/cli/src/builtin-addons/date-time/buttons/clock.tsx` — `core:clock` button (12h time)
- File: `packages/cli/src/builtin-addons/date-time/buttons/analog-clock.tsx` — `core:analog-clock` button (SVG)
- File: `packages/cli/src/builtin-addons/date-time/buttons/locked-time-tile.tsx` — `core:locked-time-tile` (single character of HH:MM)
- File: `packages/cli/src/builtin-addons/date-time/index.ts` — exports `dateTimeAddon: SirenoAddon`
- Tests: `packages/cli/src/builtin-addons/date-time/__tests__/{format,index}.test.ts`
- Acceptance: All 6 button types validate and render. `useEffect` + `setInterval(1000)` refreshes every second.

### Task 2: Port `value-display` addon
- File: `packages/cli/src/builtin-addons/value-display/schemas.ts` — `ValueDisplayButtonSchema` with `values: [{ label, command, formatter?, units?, timeout_ms?, icon? }]`
- File: `packages/cli/src/builtin-addons/value-display/buttons/value-display.tsx` — single button that runs each command via `@/action/executor.executeCommand` on a `useEffect` + `setInterval`; renders rows via `<LabelValueList>` from Phase 08
- File: `packages/cli/src/builtin-addons/value-display/index.ts` — `valueDisplayAddon`
- Tests: schema parsing + button shape
- Acceptance: 1 button type, defaults to 5s timeout per command.

### Task 3: Port `system-status` addon
- File: `packages/cli/src/builtin-addons/system-status/schemas.ts` — `SystemStatusButtonSchema` with `metrics: [{ metric, label, icon?, max_value?, color? }]`, `variant: 'text' | 'bars'`, `poll_interval_ms?` (default 1000)
- File: `packages/cli/src/builtin-addons/system-status/domain/metrics.ts` — `refreshMetrics(metricIds)` reads `os.cpus()`, `os.totalmem()`, `os.freemem()`, `os.loadavg()`, and `/sys/class/power_supply/BAT0/capacity` (Linux best-effort)
- File: `packages/cli/src/builtin-addons/system-status/buttons/system-status.tsx` — single button; uses `useEffect` + `setInterval(poll_interval_ms)`; renders `<Bars>` for `variant: 'bars'`, `<LabelValueList>` for `variant: 'text'`
- File: `packages/cli/src/builtin-addons/system-status/index.ts` — `systemStatusAddon`
- Tests: metrics parsing, schema
- Acceptance: 1 button type. Defaults: poll_interval_ms = 1000.

### Task 4: Register the 3 addons
