# Plan 34-01: Publish The Shared Command-Action Contract And Prove It On The Action Button

<objective>
Land the public command-action contract Phase 34 depends on before migrating the broader built-in surface. This slice delivers one complete behavior end-to-end: addon authors can declare nested `commands.tap`, `commands.hold`, and `commands.double-tap` on a mounted button through one shared helper, and the bundled `action` button already uses that exact contract in shipped code.
</objective>

## Tasks

<task id="34-01-01">
<title>Add the public nested command-action schema and gesture hook at the addon API seam</title>
<files>
- packages/cli/src/addon/api.ts
- packages/cli/src/index.ts
</files>
<action>
Add one reusable public command-action contract to `packages/cli/src/addon/api.ts`: a nested `commands` schema/interface with optional `tap`, `hold`, and `double-tap` entries plus a narrow `useButtonActionCommand(...)` helper that returns mounted-button `onPress`, `onRelease`, and `onTap` handlers. Keep the helper entirely addon-facing: use existing runtime methods/store, await `methods.runCommand(...)`, implement one shared hold threshold, make long press resolve to `hold`, and when both `tap` and `double-tap` exist, delay the single-tap path so `double-tap` suppresses it. Re-export the new public API from `packages/cli/src/index.ts` so addon authors can consume it through the package root.
</action>
<verify>
Run `grep -n "useButtonActionCommand\|double-tap\|commands" packages/cli/src/addon/api.ts packages/cli/src/index.ts`.
</verify>
<done>
The package exposes one truthful public schema + hook surface for command gestures, and it encodes the locked Phase 34 timing semantics without widening core runtime.
</done>
</task>

<must_haves>
- Do not add a second command execution path; keep `methods.runCommand(...)` authoritative.
- Do not move gesture policy into `packages/cli/src/deck/runtime.ts`; the helper must compose onto existing mounted-button callbacks.
- Do not auto-call `methods.invalidate()` inside the shared helper.
</must_haves>
