</objective>

<action>
Refactor the `fit="shrink"` contract so the current `.sireno-text-fit-shrink` clamp is no longer the primary implementation. Keep `Text` as the public API owner, but activate live shrink-fit measurement only on the browser DOM render path. The measured seam should seek the largest non-wrapping size from the active typography base down to one readable minimum floor, then stop; do not widen this task into configurable public fallback APIs, mounted/static measurement parity, or changes to `wrap`, `ellipsis`, and `marquee`. Build the browser measurement path defensively so repeated identical writes and resize-observer loop churn are suppressed through a loop-safe scheduling/update strategy.
</action>
