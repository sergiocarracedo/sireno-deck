# Plan 24-05: Fix Emulator Asset Serving For Mounted Built-Ins

<objective>
Close the UAT-reported built-in image breakage at the real seam: built-in icons render on the Playwright capture path because that browser can load `file://` URLs, but the user-facing emulator page cannot. This slice keeps the mounted runtime intact while giving the emulator an explicit browser-safe asset path for addon and theme assets.
</objective>
