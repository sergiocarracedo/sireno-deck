<task id="10-04-03">
<title>Apply useRef pattern to bridge.onConnection registration</title>
<files>
- packages/cli/frontend/src/ws-bridge.ts
</files>
<action>
If the audit (Task 10-04-01) found a TDZ-style issue where `bridge.onConnection` is registered AFTER `client.connect()` opens the connection, fix it using the `useRef` pattern from `.planning/solutions/best-practices/react-useeffect-tdz-closure-trap-2026-07-20.md`:

```tsx
const clientRef = useRef<WsClient | null>(null)
useEffect(() => {
  clientRef.current = createWsClient({
    onStatus: (status) => {
      setReady(clientRef.current?.attemptCount() > 0)
    },
    onAssets: (assets) => {
      // store in asset cache
      setReady(true)
    }
  })
}, [])
```

The `useRef` is assigned synchronously, the constructor's callback reads it on the next microtask (after assignment completes) — no TDZ.

If the existing code already uses `useRef`, just add a `// ponytail: useRef pattern per .planning/solutions/best-practices/react-useeffect-tdz-closure-trap-2026-07-20.md` comment and move on.

If the audit found no TDZ issue, this task is a no-op with a comment confirming the pattern was verified.
</action>
