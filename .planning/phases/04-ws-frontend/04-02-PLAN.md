# Phase 04 Plan 02 — Vite Plugin + Frontend React App

## Context

Plan 01 built the data plane (API types, protocol, bridge). This plan builds the UI shell: the vite plugin that injects addons into the frontend bundle, plus the React app skeleton with the core components.

Locked decisions from CONTEXT.md:
- **Addon frontend module loading**: build-time static import. The vite plugin reads the loaded `AddonRegistry` and emits static imports for each addon's `frontend.main` (when present).
- Vite plugin uses `virtual:sireno/token` (dev) — exposes `SIRENO_TOKEN` from env to the frontend code.

The frontend renders a deck with mock data first (no WS connection in this plan). WS wiring lands in Plan 03.
