## Context

UAT test 3 reported `DeckNavigationError: Deck 'emoji-smileys' is not defined` when tapping the multi-page Smileys category on the main deck. The existing test on line 82-86 only verified the favorites (single-page, 2 emojis) case, so the mismatch went unnoticed.

In `packages/cli/src/builtin-addons/emoji-selector/index.ts:135`, the main deck's category button uses `category.deckIdPrefix` (the base deck ID) as `target_deck`. For multi-page categories, the actual generated deck ID is `${baseDeckId}-p1` (see line 81-83). The fix is to derive `target_deck` from the actual page-1 deck ID.
