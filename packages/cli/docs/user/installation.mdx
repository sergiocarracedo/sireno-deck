# Installation

Get Sireno Deck running on your computer in minutes.

## Prerequisites

- **Node.js** 20 or later
- **pnpm**, npm, or Yarn (pnpm is preferred for addon and theme installs)
- A Stream Deck device (optional — emulator available for testing)

## Quick Install

Install the CLI globally:

```bash
pnpm i -g @sirenodeck/cli
```

The addon installer checks for pnpm, npm, or Yarn and prefers pnpm.

## From Source

```bash
# Clone the repository
git clone https://github.com/anomalyco/sireno-deck.git
cd sireno-deck

# Install dependencies
pnpm install

# Build the CLI
pnpm build

# Run directly
pnpm sireno --help
```

## Verify Installation

```bash
sireno --version
```

You should see output like:

```
sireno-deck v0.1.0
```
