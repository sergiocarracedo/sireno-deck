# Plan 18-03: Live and Runtime-Owned Browser Surfaces

<objective>
Prove the browser-only renderer is viable for the full runtime, not just static buttons. This plan keeps runtime lifecycle ownership in `runtime.ts` while converting live toggles, date/time widgets, and runtime-owned system surfaces to browser-rendered TSX so there is no hidden internal renderer keeping the old contract alive.
</objective>
