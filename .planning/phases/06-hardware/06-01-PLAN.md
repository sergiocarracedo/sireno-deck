# Phase 06 Plan 01 — Device Layer

## Context

Phase 06 wires real Elgato Stream Deck hardware. Before any rendering can happen we need to (1) enumerate connected devices, (2) persist + recall the user's selection, (3) prompt if multiple, (4) wrap the @elgato-stream-deck/node library with our own type-safe interface.

The legacy code (`/works/opensource/sireno-deck/packages/cli/src/device/`) has all of this; we port the algorithms but rewrite to fit sireno-deck's shape (single layer, smaller files, no domain leakage).

## Notes for executor

- `@elgato-stream-deck/node` v9 is current; check the npm registry. Mock it via `vi.mock` in tests so the test environment doesn't need a real device.
- `@inquirer/prompts` has a `select` API: `select({ message, choices })` returning the value of the chosen choice. Mock it similarly.
- `UDEV_RULES` is a literal string (the udev rules text); keep it as a `export const`. Don't read it from disk.
- Atomic write: `writeFileSync(path + '.tmp', data); renameSync(path + '.tmp', path)`. On error, delete `.tmp`.
- For tests using temp dirs, use `os.tmpdir()` + `mkdtempSync`. Cleanup in `afterEach`.
