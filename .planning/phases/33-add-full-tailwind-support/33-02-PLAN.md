# Plan 33-02: Hard-Cut Shared UI And Built-Ins Onto Canonical Tailwind Utilities

<objective>
Deliver one complete browser-surface tracer bullet on top of the new Tailwind delivery seam: shared UI primitives, theme presentation, and built-in browser-rendered addons all style correctly through canonical Tailwind utilities rather than the handwritten utility sheet. This is the actual product-facing cutover for shipped UI, not just tooling work.
</objective>
