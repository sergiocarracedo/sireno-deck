# Plan 53-01: Device layer — setBrightness, registry, setBrightnessAll

<objective>
The device layer is the foundation of phase 53. After this plan, the `StreamDeckDeviceHandle` interface has a `setBrightness(percentage: 0..100)` method; a new singleton registry tracks every open handle; and a `setBrightnessAll` helper iterates the registry with best-effort error handling (log + continue, return summary). The handle's `lastBrightness` is persisted across USB reconnects. The phase 54 settings deck and the phase 53 built-in brightness button both rely on this device layer.
</objective>
