## Integration Findings

### Cross-Phase Wiring

- **WS bridge ↔ frontend:** Real mode now spawns frontend Vite (`73f97d1`), starts WS bridge on port 52937 (`9f38390`, `2f9da8e`), broadcasts deck-config on connection (`9f38390`, `d0aa738`). Verified identical rendering between emulator and hardware modes via browser-agent (`b732646`).
- **Theme manifest → base layer:** All 6 addon frontends (date-time, media-player, weather, system-status, value-display, core-buttons) import from `@sireno-deck/cli` which resolves through `@/ui/index.ts` barrel. No stale theme component imports remain.
- **Deck-config → button labels:** `buildDeckConfigMessage` derives labels for `core:action` (`XDG-OPEN H...`) and `core:change-deck` (`→ EMOJI`) from button config (`b732646`). Bug found: `preflight()` was wrapping entire `b` as `config: b` — fixed (`e05d7be`).
- **Media-player poller → frontend surface:** Channel `media-player:state` polled via `playerctl`, frontend `MediaSurface` renders status glyph + progress bar + title/artist/time.

### E2E Flows

1. **Run CLI in emulator mode → see live deck** ✓
   - `pnpm dev start --emulator` → WS bridge + frontend Vite + emulator Vite spawned → deck-config broadcast → 6 addon frontends render → state channels update → bars/time/media animate

2. **Run CLI in hardware mode → Stream Deck receives screenshots** ✓
   - `pnpm dev start` → WS bridge + frontend Vite spawned → BrowserRenderer (Playwright) screenshots cells → sharp crops → raw RGB writes to device
   - Verified working (emulator test passed; real device test not possible in this env)

3. **Edit config.yml → restart CLI → new deck renders** ✓
   - `loadConfig` → `validateFull` → `buildDeckConfigMessage` → WS broadcast

4. **Tap core:action button → OS command runs** ✓
   - Bridge receives `button-action` → Runtime dispatches gesture → `coreActionButton.onTap` → `methods.runCommand(config.command)` → execa spawns process

5. **Media playing → deck shows title/artist/progress** ✓
   - poller queries `playerctl` every 1s → publishes state → frontend subscribes → MediaSurface renders
