# Installation

Get Sireno Deck running on your computer in minutes.

## Prerequisites

- Homebrew on macOS or Linux; Windows users can use Homebrew through WSL
- A Stream Deck device (optional — emulator available for testing)

## Quick Install

Install the CLI with Homebrew:

```bash
brew install sergiocarracedo/tap/sirenodeck
```

Homebrew is supported on macOS and Linux, including Windows Subsystem for Linux (WSL).

## Node.js install (for developers and native Windows)

For development environments, or to install on native Windows without WSL, use Node.js 20 or later and a package manager:

```bash
pnpm i -g @sirenodeck/sirenodeck
```

You can also use npm or Yarn:

```bash
npm i -g @sirenodeck/sirenodeck
yarn global add @sirenodeck/sirenodeck
```

The addon installer checks for pnpm, npm, or Yarn and prefers pnpm.

Install the optional global agent skill to configure and update decks with your
preferred coding agent:

```bash
sirenodeck skills
```

The first interactive startup also offers to install it. Use `sirenodeck skills
--yes` to skip the confirmation and install for all agents supported by the
skills CLI, or use `--agent <id>` to target specific agent(s).

## From Source

```bash
# Clone the repository
git clone https://github.com/sergiocarracedo/sireno-deck.git
cd sireno-deck

# Install dependencies
pnpm install

# Build the CLI
pnpm build

# Run directly
pnpm sirenodeck --help
```

## Verify Installation

```bash
sirenodeck --version
```

You should see output like:

```
sirenodeck v0.2.1
```
