# Plan 05-02: Truthful External Source-Edit Refresh

<objective>
Preserve the external `tsx watch` loop as the honest source-edit refresh mechanism and make that boundary visible in tests and docs. This slice is demoable on its own because a developer can edit source-owned files and know exactly which seam restarts the real CLI process, instead of depending on accidental module-cache behavior inside the daemon.
</objective>
