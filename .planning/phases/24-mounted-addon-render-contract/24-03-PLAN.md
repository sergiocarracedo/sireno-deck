# Plan 24-03: Mounted Active-Deck Root and Transient Runtime Props

<objective>
Replace the active-deck static markup path with the real mounted-tree behavior the phase promised: while a deck is active, its React tree stays mounted inside the persistent browser page and can preserve component-local state; runtime-driven transient props still come from Node immediately; leaving the deck unmounts that tree cleanly.
</objective>
