# Phase 12 Plan 03: 7 addon frontend.tsx files

## Tasks

### Task 1: date-time frontend

- File: `packages/cli/src/builtin-addons/date-time/frontend.tsx` (new)
- Default export `Component<{ config; state }>`.
- Subscribes to `date-time:now` channel (`{ now: number }`).
- Renders based on `config`:
  - `core:time` → format `HH:mm` or `HH.mm` (big variant).
  - `core:date` → format `day + month + weekday`.
  - `core:clock` → format `HH:mm` (with optional seconds).
  - `core:analog-clock` → SVG analog clock face (already implemented in legacy).
  - `core:date-time` → format `config.format` string.
  - `core:locked-time-tile` → single HH:MM character at `config.slot`.
- Uses theme tokens (`text-fg`, `text-muted`, `bg-bar`).

### Task 2: weather frontend

- File: `packages/cli/src/builtin-addons/weather/frontend.tsx` (new)
- Subscribes to `weather:current` channel (`{ available, temperature, windSpeed, description }`).
- Renders `<LabelValueList>` with temperature, wind, conditions.
- If `state.available === false`, shows "Configure weather" or last-known.

### Task 3: system-status frontend

- File: `packages/cli/src/builtin-addons/system-status/frontend.tsx` (new)
- Subscribes to `system-status:metrics` channel (`{ metricId: value }`).
- Renders `<Bars>` for `variant: bars` or `<LabelValueList>` for `variant: text`.
- Uses theme tokens.

### Task 4: media-player frontend

- File: `packages/cli/src/builtin-addons/media-player/frontend.tsx` (new)
- Subscribes to `media-player:state` channel (`{ title, artist, isPlaying, volume, canGoNext, canGoPrev }`).
- Renders `<SplitAction>`: left half = prev/play-pause/next, right half = volume + scrubber.
- Tap = play/pause; dbl-tap = next; hold = previous (or send to `useButtonAction`).

### Task 5: value-display frontend

- File: `packages/cli/src/builtin-addons/value-display/frontend.tsx` (new)
- Subscribes to `value-display:values` channel (`{ label, value }[]`).
- Renders `<LabelValueList>` with each value.

### Task 6: brightness frontend

- File: `packages/cli/src/builtin-addons/brightness/frontend.tsx` (new)
- Subscribes to `brightness:current` channel (`{ value: number; max: number }`).
- Renders a horizontal bar with the current brightness %.
- Tap = `useButtonAction(buttonId)("up")` (or down, based on config).

### Task 7: emoji-selector frontend

- File: `packages/cli/src/builtin-addons/emoji-selector/frontend.tsx` (new)
- Subscribes to `emoji-selector:copied` channel (for recent-copy indicator).
- Each button just renders the emoji character (theme surface is fine; no special component needed unless we want a category header).
- Tap = `useButtonAction(buttonId)("copy")` which copies to clipboard.

### Task 8: Update each addon's `index.ts`/`index.tsx` with `frontend` field + `publishIntervalMs`

- For each of the 7 addons above, update the addon manifest:
  - `frontend: { main: "./frontend.tsx" }`
  - `publishIntervalMs: <value>` (1000 for time/metrics, 600000 for weather, 2000 for media/brightness, 5000 for value-display).

### Task 9: Verify rendering in browser

- Start `pnpm --filter sireno-deck dev start --emulator`.
- Open `http://127.0.0.1:52938/`.
- Verify each button shows the real surface (clock ticking, weather, CPU bars, etc.) — not the type-name label.

### Task 10: Tests + typecheck + lint

- Update the addon's `__tests__` to assert `manifest.frontend` is set.
- New test: addon registry contains all 7 user-facing addons.
- All existing 464 tests pass.
- `pnpm --filter sireno-deck typecheck` clean.
- `pnpm --filter sireno-deck lint` clean.
