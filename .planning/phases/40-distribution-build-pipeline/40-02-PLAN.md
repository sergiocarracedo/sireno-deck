## Tasks

### 40-02-01: Add getSeaAsset helper

- **file**: `packages/cli/src/util/sea-asset.ts`
- **action**: |
  Create a runtime helper that reads an asset from the SEA bundle when running in a SEA, falling back to filesystem read in dev mode. This isolates the `node:sea` import to one place and keeps existing code paths clean.

  ```ts
  import { readFileSync } from 'node:fs'
  import { fileURLToPath } from 'node:url'
  import { isSea, getAsset } from 'node:sea'

  export function getSeaAsset(name: string): Buffer {
    if (isSea()) {
      return Buffer.from(getAsset(name))
    }
    const path = fileURLToPath(new URL(`../assets/${name}`, import.meta.url))
    return readFileSync(path)
  }

  export function isSeaBuild(): boolean {
    return isSea()
  }
  ```

  Note: `import.meta.url` returns `node:` in SEA mode, breaking relative paths — that's why we use `getAsset()` first.
- **verify**: `cd packages/cli && npx tsx -e "import {getSeaAsset, isSeaBuild} from './src/util/sea-asset.ts'; console.log('isSea:', isSeaBuild()); console.log('logo size:', getSeaAsset('logoFull.png').length)"`
- **done**: Helper exists, exports `getSeaAsset(name)` and `isSeaBuild()`. Dev mode returns file bytes; SEA mode returns embedded bytes.

