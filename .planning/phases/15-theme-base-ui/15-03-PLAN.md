<objective>
Mount the `ThemeUiPresentationProvider` in the Vite frontend entry point so that the React context is available to all components in the tree. Populate it from the active theme's `ui` export. Then verify that all 6 addon frontends render correctly through the base layer — no visual regressions from the Phase 13 state. </objective>
