# 60-01 — Pagination button 3-line layout

> Phase 60 decisions: (1) Add `currentPage`/`totalPages` to `PageNavButtonConfig` so the render can show "Page X/Y" without runtime introspection. (2) Use the shared `<Label>` component for each of the 3 lines (PAG-03). (3) Handle tap/dbltap no-op cases by hiding the unavailable line.

## Context

The current pagination button renders a centered chevron icon with optional "Tap" / "Dbl Tap" chips at the corners. The new design replaces this with a 3-line text layout per PAG-02:

```
  Tap >
 < 2xTap
  Page 1/5
```

The render is detected by `config.meta === 'page-nav'` in `change-deck.tsx:79-95`. The data needed for the third line ("Page X/Y") is `currentPage` and `totalPages`, which are already passed to `buildPageNavButton` as arguments but not threaded into the returned config.

### Task 3: Replace the page-nav render in change-deck.tsx

**File:** `packages/cli/src/builtin-addons/core-buttons/buttons/change-deck.tsx`

Replace `renderPageNavContent` (lines 43-57) and its call site (lines 79-95) with a new 3-line component. The new render:

```typescript
function renderPageNavContent(
  config: PageNavButtonConfig,
  isMainDeck = false,
) {
  if (isMainDeck) {
    return (
      <div className="flex flex-col items-center justify-center w-full h-full">
        <Icon name="chevron-right" size={20} />
      </div>
    )
  }

  const tapNoop = config.target_deck === config.target_deck_double_tap
  const doubleTapNoop =
    config.target_deck_double_tap === undefined ||
    config.target_deck_double_tap === config.target_deck

  return (
    <div className="flex flex-col items-center justify-center w-full h-full gap-0.5">
      {tapNoop ? null : <Label>Tap &gt;</Label>}
      {doubleTapNoop ? null : <Label>&lt; 2xTap</Label>}
      <Label>Page {config.currentPage}/{config.totalPages}</Label>
    </div>
  )
}
```

Notes:
- Uses `<Label>` (per PAG-03) for each line. The shared component handles overflow via `fit="ellipsis"`.
- The 3 lines are stacked vertically with `gap-0.5` (small spacing). The font size is `text-md` from `<Label>`'s default; no additional sizing needed for the typical 15-key grid.
- The isMainDeck case (position 14) keeps the current chevron-only behavior (this is for the system back button area on the main deck, not the page-nav itself).
- The `tapNoop` and `doubleTapNoop` logic is unchanged from the existing implementation; just the rendering of the unavailable line is `null` (hidden) instead of removing the chevron.
- Import `PageNavButtonConfig` from `@/core/pagination` for the new param type.
- Update the call site in the render branch (lines 79-95) to pass `config` instead of `config.target_deck`.
