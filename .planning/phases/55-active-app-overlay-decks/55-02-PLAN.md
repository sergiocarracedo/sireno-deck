# Plan 55-02: Runtime overlay state + dismiss gestures

<objective>
This plan wires the runtime to the active-app monitor. The runtime maintains an `overlayDeckId: string | null` state field and subscribes to the monitor. When the monitor fires a snapshot that matches a registered addon-declared `process_name` (case-insensitive substring, OS-suffix stripped), the runtime sets `overlayDeckId` to that deck's ID; when the snapshot doesn't match, the runtime resets to `null`. The overlay renders on top of the base deck — the base stack is never modified.

The reserved-slot button on an overlay deck is a "Base" toggle (icon + "Base" label) that calls a new `dismissOverlay()` method. A 350ms double-tap on any back action dismisses the overlay (and skips the base-stack pop for the 2nd tap).

The plan is verifiable on its own: integration tests inject a `createActiveAppMonitorDouble` into the runtime, emit synthetic snapshots, and assert the overlay pushes/dismisses correctly. The system-back-button component gets a new `isOverlay` prop and a test for it.
</objective>

```ts
export function processNamesMatch(
  declared: readonly string[],
  active: string,
  platform: NodeJS.Platform,
): boolean {
  const normalizedActive =
    platform === 'darwin'
      ? active.replace(/\.app$/i, '')
      : platform === 'win32'
        ? active.replace(/\.exe$/i, '')
        : active
  const lowerActive = normalizedActive.toLowerCase()
  return declared.some((name) => lowerActive.includes(name.toLowerCase()))
}
```

```ts
function handleActiveAppChange(snapshot: ActiveAppSnapshot): void {
  if (!snapshot) {
    if (overlayDeckId !== null) {
      overlayDeckId = null
      void renderDeckSurface(getDisplayDeckId(), activeActivationVersion).catch(
        reportRuntimeError,
      )
    }
    return
  }
  // Find first matching addon deck by load order
  const newOverlay = findActiveAppDeckFor(snapshot.ownerName)
  if (newOverlay !== overlayDeckId) {
    overlayDeckId = newOverlay
    void renderDeckSurface(getDisplayDeckId(), activeActivationVersion).catch(
      reportRuntimeError,
    )
  }
}
```
