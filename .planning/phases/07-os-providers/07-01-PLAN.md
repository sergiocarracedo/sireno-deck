# Phase 07 Plan 01 — Interfaces + Linux Implementations

## Context

Phase 07 delivers cross-platform OS automation (R15/R16). The four provider interfaces are locked in `07-CONTEXT.md`; this plan builds the foundation (interfaces + error types + null provider pattern) and the Linux implementations, the highest-priority platform (per user environment).

The `dbus-next@^0.10.0` library is the primary dependency for active-app + session on Linux; `get-windows` for active-app fallback; `playerctl` (system binary) for media; `xdotool`/`ydotool`/`dotool` for key-macro. All native calls mocked at the module boundary in tests.

<action>Create `provider.ts` exporting:
- `ProviderError` class extending `Error` with `code: 'NOT_AVAILABLE' | 'TIMEOUT' | 'EXEC_FAILED' | 'PARSE_ERROR' | 'UNSUPPORTED_PLATFORM'`.
- `ActiveAppSnapshot` interface: `{ name: string, windowTitle: string | null, processId: number | null }`.
- `ActiveAppProvider` interface: `{ getActive(): Promise<ActiveAppSnapshot | null>, subscribe(handler: (s: ActiveAppSnapshot | null) => void): () => void, stop(): Promise<void> }`.
- `SessionState` type: `'locked' | 'unlocked' | 'unknown'`.
- `SessionProvider` interface: `{ getState(): SessionState, subscribe(handler: (s: SessionState) => void): () => void, stop(): Promise<void> }`.
- `KeyMacroProvider` interface: `{ sendKey(comboOrText: string): Promise<void>, stop(): Promise<void> }`. `sendKey` throws `ProviderError`.
- `MediaMetadata` interface: `{ title: string, artist: string | null, album: string | null, artUrl: string | null }`.
- `MediaProvider` interface: `{ play(): Promise<void>, pause(): Promise<void>, toggle(): Promise<void>, next(): Promise<void>, previous(): Promise<void>, getCurrent(): Promise<MediaMetadata | null>, onChange(handler: (m: MediaMetadata | null) => void): () => void, stop(): Promise<void> }`.
- `createNullActiveAppProvider(reason: string): ActiveAppProvider` — logs `WARN { reason }` and returns a provider where `getActive` resolves to `null` and `subscribe` returns a no-op unsubscribe.
- `createNullSessionProvider(): SessionProvider` — `getState` returns `'unknown'`, subscribe is a no-op.
- `createNullKeyMacroProvider(): KeyMacroProvider` — `sendKey` throws `ProviderError({ code: 'NOT_AVAILABLE' })`.
- `createNullMediaProvider(): MediaProvider` — `getCurrent` resolves to `null`, transport methods throw `ProviderError({ code: 'NOT_AVAILABLE' })`.
- Helper `withTimeout<T>(promise, ms, code?): Promise<T>` that races the promise against a setTimeout and throws `ProviderError({ code: 'TIMEOUT' })` on timeout.</action>

<action>Implement `createLinuxActiveAppProvider({ bus, executor, logger })` (exported as `createActiveAppProvider` from `index.ts`). Logic:
1. Try D-Bus: call `org.gnome.Shell` → `Eval` with `global.display.focus_window` (cast to JSON.parse) to get focused window's `{ wm_class, title, pid }`.

3. `getActive()` returns `{ name, windowTitle: wm_class || comm, processId: pid || null }`.
4. Internal poll loop every 1s, compares snapshot to last, calls subscribers on change.
5. `stop()` clears interval and disconnects D-Bus bus.
6. On D-Bus connect error, return `createNullActiveAppProvider('dbus-unavailable')`.
All shell commands via the `executor` (testable).
All D-Bus calls via the `bus` (testable; production uses `dbus-next`).</action>

<file>packages/cli/src/system/key-macro/linux.ts</file>
<action>Implement `createLinuxKeyMacroProvider({ executor, env, logger })` (exported as `createKeyMacroProvider`). Logic:
1. Probe at init: `which xdotool` then `which ydotool` then `which dotool`. If `$XDG_SESSION_TYPE === 'x11'`, try `xdotool` first; if `'wayland'`, try `ydotool` first; else walk in order.
2. Cache the chosen binary. Log INFO `{ tool: 'xdotool' }` (etc).
3. `sendKey(input)`:
   - If `parseCombo(input) !== null`: convert to platform syntax (`xdotool key ctrl+t`; `ydotool key ctrl+t`; `dotool key ctrl+t`). Run via executor. Throw `ProviderError({ code: 'EXEC_FAILED' })` on non-zero exit.
   - Else: send as literal keystrokes. For `xdotool`: `xdotool type -- "text"` (handles emojis). For `ydotool`: same syntax. For `dotool`: `dotool type "text"`.
4. Timeout 5s per call via `withTimeout`.
5. If no tool found, return `createNullKeyMacroProvider()` (log WARN `{ reason: 'no key tool found' }`).</action>
<verify>`tsc --noEmit` clean.</verify>
