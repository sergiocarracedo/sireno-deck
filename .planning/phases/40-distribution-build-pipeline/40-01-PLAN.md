### 40-01-06: Smoke test the binary

- **file**: `packages/cli/scripts/smoke-test-sea.mjs` (new)
- **action**: |
  Add a small post-build smoke test that runs the binary with `--version` and `--help` and asserts exit 0 and expected output. Take the binary path as CLI arg. Used by the build script and the CI matrix (Phase 47).

  ```js
  #!/usr/bin/env node
  import { spawnSync } from 'node:child_process'
  import { existsSync } from 'node:fs'

  const binaryPath = process.argv[2]
  if (!binaryPath || !existsSync(binaryPath)) {
    console.error(`smoke: binary not found: ${binaryPath}`)
    process.exit(1)
  }

  for (const flag of ['--version', '--help']) {
    const result = spawnSync(binaryPath, [flag], { encoding: 'utf8' })
    if (result.status !== 0) {
      console.error(`smoke: ${flag} exit ${result.status}`)
      console.error(result.stderr)
      process.exit(1)
    }
    if (!result.stdout.length) {
      console.error(`smoke: ${flag} produced no output`)
      process.exit(1)
    }
  }
  console.log(`smoke: ${binaryPath} OK`)
  ```

  Wire it into the build script: after `chmod +x`, call `node scripts/smoke-test-sea.mjs ${outputPath}`. If smoke fails, the build fails.
- **verify**: `cd packages/cli && SIRENO_TARGET=linux-x64 SIRENO_DIST_DIR=/tmp/sireno-test pnpm run build:sea` and observe `smoke: /tmp/sireno-test/linux-x64/sireno OK` in the output
- **done**: Smoke test runs after every build; build fails if --version or --help fail.
