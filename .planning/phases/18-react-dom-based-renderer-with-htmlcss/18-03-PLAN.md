# Plan 18-03: Live TSX Buttons and Capture Coalescing

<objective>
Prove that the new browser renderer is not just for static buttons. This plan preserves the current runtime-owned live-update model for toggles and date/time widgets while introducing the bounded full-deck recapture/coalescing policy chosen for Phase 18. The result should be a demoable live deck that updates honestly through the browser surface without backlogging stale frames.
</objective>
