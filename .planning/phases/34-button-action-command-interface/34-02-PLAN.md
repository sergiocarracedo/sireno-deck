# Plan 34-02: Migrate System-Status Onto The Shared Command-Action Contract

<objective>
Deliver one complete built-in migration on top of the new contract: both shipped system-status buttons accept nested command gestures through the shared helper and keep their existing polling-driven UI behavior truthful. This slice proves the contract can replace duplicated local timers on a real addon with existing state, cadence, and unavailable rendering complexity.
</objective>
