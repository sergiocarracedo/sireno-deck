### How the emulator mode flows

1. User runs `pnpm emulate` (or sets `SIRENO_EMULATE=1` and runs `pnpm start`).
2. CLI spawns Vite + headless Chromium-less pipeline + WS bridge.
3. Vite serves `emulator.html` at root → mounts `EmulatorShell` → opens WS connection.
4. User selects a device (3/6/15/32-key); IframeCanvas resizes the iframe to match.
5. User clicks over the iframe → overlay div catches mouseup → translates to `keyIndex` → sends `button-action` over WS.
6. CLI receives `button-action`, logs it (and in real hardware mode, would write to the Stream Deck device).
7. CLI's deck-config sendDeckConfig flows back over WS → emulator's action log / deck display updates.
