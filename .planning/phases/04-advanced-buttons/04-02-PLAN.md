# Plan 04-02: CPU and memory live-data buttons

<objective>
Deliver the Phase 4 live-metric slice for CPU and memory buttons. This plan uses the polling foundation from 04-01, adds a narrow system metrics adapter, and proves the rich built-in layout path with concrete progress/text metric buttons.
</objective>

## Tasks

<task id="04-02-01">
<title>Add CPU and memory button schemas plus a systeminformation adapter</title>
<files>
- config.yml
- packages/cli/package.json
- packages/cli/src/core/schemas.ts
- packages/cli/src/system/live-metrics.ts
- packages/cli/src/system/live-metrics.test.ts
</files>
<action>
Add the `systeminformation` runtime dependency to `packages/cli/package.json`. Create `packages/cli/src/system/live-metrics.ts` as a narrow adapter that exposes only the CPU and memory values Phase 4 needs for button rendering, keeping platform quirks out of runtime code. Extend `packages/cli/src/core/schemas.ts` with built-in `cpu` and `memory` button schemas that validate interval settings and whichever display-mode/config fields are needed for the approved rich built-in layouts. Update `config.yml` with representative CPU and memory examples.
</action>
<verify>
grep 'systeminformation' packages/cli/package.json && ls packages/cli/src/system/live-metrics.ts && grep 'type: z.literal("cpu")\|type: z.literal("memory")' packages/cli/src/core/schemas.ts
</verify>
<done>
The codebase has a dedicated live-metrics adapter and validated CPU/memory button config shapes wired into the example config.
</done>
</task>
