# 57-02 — Design + audit docs (RES-02, RES-03)

> Phase 57 has three research items. Plan 57-01 covers RES-01 (live profile). This plan covers the documentation outputs for RES-02 (pasteText wiring design) and RES-03 (emoji category audit), then finalizes the single RESEARCH.md.

## Context

Phase 57 decision (CONTEXT.md, Option A): `methods.pasteText` becomes a thin wrapper in `createDeckRuntime` that calls `keyMacroProvider.send(platformPasteKey)` after `clipboardy.write()`. Existing `clipboard.ts` stays pure. The wrapper lives in the runtime factory, not in `clipboard.ts`, so the dependency is one-directional and testable.

Phase 57 decision (RES-03, data audit only): Confirmed `categories.json` has zero overlap between smileys (41 chars) and people (41 chars). User perception of "duplication" is likely visual (launcher grid contains `😂` which also appears in smileys category). Defer perception to UX feedback backlog.

Output format: single `57-RESEARCH.md` with three sections: `## RES-01 Profile Trace`, `## RES-02 pasteText Design`, `## RES-03 Category Audit`. Plan 57-01 writes the RES-01 section; this plan writes RES-02 and RES-03.
