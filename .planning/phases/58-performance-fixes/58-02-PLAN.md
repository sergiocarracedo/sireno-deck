# 58-02 — Skip capture when HTML unchanged

> Phase 58-01 will identify the dominant capture-loop hop. The CONTEXT.md decision is to ship a "skip capture when HTML unchanged" fix as the primary mitigation. This plan delivers both PERF-01 and PERF-02 success criteria from ROADMAP.md.

## Context

Phase 58-01 profile analysis (RESEARCH.md Profile Analysis section, populated by Plan 58-01) identifies which hop dominates. The CONTEXT.md-decided fix is:
- Cache the hash of the last-rendered HTML
- In `runCaptureLoop`, before `activePage.screenshot`, compute sha1 of `requestedHtml`
- If hash matches the last-rendered hash AND `renderedVersion === requestedVersion`, skip the screenshot — reuse `lastCapturedBuffers`
- Force a capture if `renderedVersion === 0` (first render) regardless of hash
- If the profile revealed that back button and weather page have different root causes, split this plan into two sub-fixes (one per scenario)

Phase 58 success criteria (ROADMAP.md):
- Back button tap → previous deck visible completes in <200ms
- Weather daily/hourly page transitions complete in <300ms
- No regressions in any existing test suite

## Tasks

### Task 1: Add HTML-hash skip-when-unchanged to runCaptureLoop

**File:** `packages/cli/src/render/browser-renderer.ts`

In the `createBrowserRenderer` closure, add:
- `let lastRenderedHtmlHash: string | null = null`
- `let lastRenderedHtmlLength: number = 0` (cheap length pre-check to skip the hash when length differs)

In `runCaptureLoop`, before `const capture = await activePage.screenshot(...)` (line ~346):

```ts
// Cheap pre-check: if the length is the same AND the html matches the last-rendered hash,
// we can skip the screenshot entirely — the rendered output is provably the same.
const canSkipCapture = renderedVersion > 0 &&
  requestedHtml.length === lastRenderedHtmlLength &&
  computeHtmlHash(requestedHtml) === lastRenderedHtmlHash

if (canSkipCapture && lastCapturedBuffers) {
  // Skip screenshot; reuse cached buffers; advance the version so captureKeyBuffers waiters resolve
  renderedVersion = Math.max(renderedVersion, requestedVersion)
  await frameHandler?.({ buffers: lastCapturedBuffers, reason: 'unchanged', version: requestedVersion })
  resolveCaptureWaiters()
  continue
}

// Update the hash after we know we'll capture
lastRenderedHtmlLength = requestedHtml.length
lastRenderedHtmlHash = computeHtmlHash(requestedHtml)
```

Where `computeHtmlHash` is a helper:

```ts
import { createHash } from 'node:crypto'
function computeHtmlHash(html: string): string {
  return createHash('sha1').update(html).digest('hex')
}
```

**Verify:** Build succeeds. `pnpm cli:dev emulate` runs normally.
**Done:** Hash skip implemented.
