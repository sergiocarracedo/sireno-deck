## Context

CONTEXT.md locked the entry button as a first-class addon-provided button type:
- 2×3 grid of six representative emojis
- Full-surface, no card chrome
- Tap = `navigateToDeck(target_deck)`
- Minimal config: `{ target_deck: string, label?: string }`

RESEARCH.md flagged a name-collision risk: the existing per-emoji entry button is also typed `'emoji-entry-button'`. Resolution: rename the existing to `'emoji-emoji-button'` (or `'emoji-pick-button'`) and use `'emoji-launcher'` for the new entry. CHANGELOG must flag the rename.

The six representative emojis chosen for visual distinctness at small sizes: 😂 🔥 ❤️ ⭐ 🍕 🎵. Document the selection in the addon code.
