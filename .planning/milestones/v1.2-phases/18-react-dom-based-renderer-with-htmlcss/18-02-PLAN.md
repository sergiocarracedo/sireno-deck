# Plan 18-02: Remove the Old Renderer Contract

<objective>
Turn the first tracer bullet into the actual shipped contract by removing the old renderer rather than keeping it as compatibility drag. This plan deletes `text-image.ts`, removes the legacy `deck-*`/`DeckButtonProps` seam from the supported path, and migrates additional bundled buttons onto browser-rendered TSX so the cleanup is real instead of partial.
</objective>

## Tasks

<task id="18-02-01">
<title>Delete the SVG renderer and browserless startup dependencies</title>
<files>
- packages/cli/src/render/text-image.ts
- packages/cli/src/render/text-image.test.ts
- packages/cli/src/cli/commands/start.ts
- packages/cli/src/cli/commands/start.test.ts
</files>
<action>
Remove `packages/cli/src/render/text-image.ts` and its test file entirely now that shared preset constants live elsewhere. Update `start.ts` and its tests so nothing imports or references `renderTextImage`, `renderBlankKeyImage`, or text-image fallback behavior anymore. Keep only the browser-backed capture path in the live daemon.
</action>
<verify>
Run `test ! -e packages/cli/src/render/text-image.ts && test ! -e packages/cli/src/render/text-image.test.ts && ! grep -n "text-image\|renderTextImage" packages/cli/src/cli/commands/start.ts packages/cli/src/cli/commands/start.test.ts`.
</verify>
<done>
The old SVG renderer module is gone and the shipped daemon no longer references it.
</done>
</task>

</task>
