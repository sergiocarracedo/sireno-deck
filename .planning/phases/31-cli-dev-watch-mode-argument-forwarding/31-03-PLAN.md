# Plan 31-03: Close The Temp Theme Runtime Watch Loop

<objective>
Close the real runtime bug that UAT exposed: the repaired `cli:dev` launcher works, but the watched process immediately destabilizes itself because theme runtime imports are copied into temp snapshot directories and then deleted, which `tsx watch` treats as dependency unlink events. This slice should make the theme runtime import path truthful for watch mode by reusing a stable import boundary instead of generating ephemeral watched files, then pin that behavior in focused regression coverage and preserve the diagnosed UAT evidence.
</objective>
