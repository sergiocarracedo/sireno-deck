# Phase 05 Plan 02 — Emulator Shell (side panel + iframe)

## Context

Phase 05's user-visible shell. A second Vite app (separate from `packages/cli/frontend/`) renders:

- **Side panel** (left): deck picker dropdown, action log placeholder, WS message log placeholder, state inspector placeholder
- **Center**: an iframe pointing at the frontend vite URL (default `http://127.0.0.1:<port>`)

For Phase 05 Plan 02 we ship the shell layout + iframe + side panel placeholders. Mouse-to-gesture wiring + WS client for action injection come in Plan 03.

Workspace layout: a new package `packages/cli/emulator/` (sibling of `packages/cli/frontend/`). Add to `pnpm-workspace.yaml`.
