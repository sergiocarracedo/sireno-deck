## Context

CONTEXT.md locked the rendering as: native emoji font stack as the default fallback, 12 branded SVG icons kept as deliberate overrides, larger glyphs per button (the "emoji image must be bigger" feedback). The current `getEmojiFallbackLabel` returns a `U+1Fxxx` text label which renders as the literal text "U+1F525" in the browser — that's the bug. This plan replaces that path with a real-emoji render and adds the size step.
