# Installation

Get Sireno Deck running on your computer in minutes.

import CommandTabs from "@site/components/CommandTabs.astro"

## Prerequisites

- **Node.js** 20 or later
- **pnpm** 8 or later (or npm/yarn)
- A Stream Deck device (optional — emulator available for testing)

## Quick Install

Install the CLI globally with your package manager of choice — the choice is
remembered across all command examples on this site:

<CommandTabs
  pnpm="pnpm i -g @sirenodeck/cli"
  npm="npm i -g @sirenodeck/cli"
  yarn="yarn global add @sirenodeck/cli"
/>

## From Source

```bash
# Clone the repository
git clone https://github.com/anomalyco/sireno-deck.git
cd sireno-deck

# Install dependencies
pnpm install

# Build the CLI
pnpm build

# Run directly
pnpm sireno --help
```

## Verify Installation

```bash
sireno --version
```

You should see output like:

```
sireno-deck v0.1.0
```
