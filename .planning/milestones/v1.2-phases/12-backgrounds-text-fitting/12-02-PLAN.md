# Plan 12-02: Ship Explicit Shrink And Wrap Text Fitting

<objective>
Deliver the second half of Phase 12 as one demoable tracer bullet: the render contract exposes explicit fit modes, shared/default text shrinks to a renderer-owned readable floor before clipping, wrap mode is opt-in and visibly different, and the repo ships a fixture plus tests that prove the behavior without dragging bespoke variants through a full rewrite.
</objective>

<action>
Implement the Phase 12 fit behavior in `packages/cli/src/render/text-image.ts` for the shared/default text path only, and land it on the primary shared label slot first rather than trying to migrate every subtitle/detail/value slot in one step. The default should shrink text until a renderer-owned readable minimum is reached, then clip cleanly rather than collapsing into unreadable micro-text. `wrap` should render an observably different multi-line layout on the same shared/default path. While doing this, decouple shared-wrapper selection from the old `overflow` field so removing `overflow` does not silently change wrapper behavior. Add targeted renderer tests that prove shrink stays inside its region, wrap changes the occupied pixel regions meaningfully, and the existing bespoke variant review paths do not silently regress.
</action>

</done>
