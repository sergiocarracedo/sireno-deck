# Plan 73-01: pasteText actually pastes

<objective>
BUG-05: `methods.pasteText(text)` currently only writes to clipboard via `clipboardy`. It never simulates the OS paste keystroke. Fix: after writing to clipboard (using synchronous `writeSync`), reuse the existing `keyMacroProvider.send(parseKeyMacro('ctrl+v'))` to inject the paste keystroke. The runtime `pasteText` handler wraps in try/catch and surfaces failures via `showRuntimeButtonError` with a new error kind `"paste"`.
</objective>

<action>
Modify `pasteText` to accept an optional `keyMacroProvider` parameter and:
1. Call `clipboardy.writeSync(text)` instead of `await clipboardy.write(text)` to ensure clipboard is populated before keystroke fires
2. If a `keyMacroProvider` is provided, call `await keyMacroProvider.send(parseKeyMacro('ctrl+v'))` after the clipboard write
3. Keep the function exported as `pasteText` (no rename) and keep `checkPasteAvailable` unchanged

```ts

```
Import `KeyMacroProvider` type:
```ts

```

New signature:
```ts
export async function pasteText(
  text: string,
  keyMacroProvider?: KeyMacroProvider,
): Promise<void> {
  clipboardy.writeSync(text)
  if (keyMacroProvider) {
    await keyMacroProvider.send(parseKeyMacro('ctrl+v'))
  }
}
```

  }
},
