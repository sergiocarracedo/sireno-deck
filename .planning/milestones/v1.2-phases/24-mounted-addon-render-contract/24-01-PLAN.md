# Plan 24-01: New Contract With Compatibility Proof

<objective>
Land the first honest tracer bullet for Phase 24: one addon button can run on the new `render(props)` contract with definition-level handlers, but the shipped runtime still boots existing instance-first definitions while the broader migration is underway. This slice proves the new contract is real without forcing a repo-wide breaking switch on day one.
</objective>
