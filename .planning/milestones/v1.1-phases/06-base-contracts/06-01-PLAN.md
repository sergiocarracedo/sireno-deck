# Plan 06-01: Explicit JSX Authoring Contract

<objective>
Add a dedicated TypeScript-only entrypoint that addon authors can opt into to use `deck-button`, `deck-text`, and `deck-surface` directly in JSX. Keep the runtime contract unchanged by reusing the existing reconciler prop types and preserving all helper-based authoring paths, so this plan delivers authoring ergonomics without widening the renderer API.
</objective>
